# ContextTrace-Unseen-v2 preregistration

This protocol must be committed before candidate freeze and corpus generation.
Changing it after labels or candidate predictions exist invalidates the
confirmatory evaluation.

## Primary tracks

The primary Natural OOD track contains 300 real RAG traces stratified equally
across software/product documentation, policy/regulatory material, and
support/operational knowledge bases. The temporal/source-condition track
contains 100 traces from 20 versioned or authority-contrasting source pairs.
Source family, source document, normalized content, domain ID, and publication
window are group-disjoint from all development and calibration registries.

Outputs are generated by the frozen retrieval configurations and two pinned
local generator models. Failures arise naturally from retrieval and generation;
no answer is manually corrupted. Neither ContextTrace nor any competitor is run
during acquisition or generation.

## Frozen outputs

The candidate emits the versioned claim-verification v2 JSON schema. The fields
scored are claim verdict, failure label, primary observable root cause, citation
state, source condition, abstention requirement, diagnostic confidence, route,
and exact evidence spans. Aggregation rules operate on exact candidate claim IDs
and the frozen answer offsets; no post-hoc remapping is permitted.

## Metrics

All metrics in `METRICS.json` are reported even when a gate fails. The primary
metrics are failure-label macro-F1, observable root-cause accuracy,
unverifiable F1, dangerous false-green rate, evidence-span token-F1 and
character IoU, expected calibration error, risk-coverage/AURC, p50/p95 latency,
and physical NLI invocation rate.

The primary baseline comparison is paired on identical traces. A baseline that
cannot produce a native fine-grained field is marked unavailable for that field;
no label or score is imputed.

## Statistical analysis

Confidence intervals use 10,000 source-family cluster-bootstrap replicates with
the fixed seed in `METRICS.json`. Paired system comparisons use 100,000
source-family sign-flip randomization replicates. Confirmatory p-values use
Holm correction across the declared primary comparisons. The confidence level
is 95 percent. Cases are never resampled as if examples from one source were
independent.

## Claim gates

A narrow SOTA claim is permitted only if every SOTA candidate gate in
`METRICS.json` passes and the full integrity audit reports no exception. A
failed gate is reported as a negative result. Inspecting case-level test errors
retires Unseen-v2 to development data and requires a newly collected test split
for a future confirmatory run.

## Annotation gate

After the unlabeled manifest is frozen, two independent annotators label the
declared headline subset or full corpus using the existing field-level manual.
Agreement is reported separately for every field, disagreements are preserved,
and adjudication occurs without access to system identity or predictions. Gold
labels remain inaccessible to implementers until the candidate run is sealed.
