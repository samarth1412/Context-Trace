# ContextTrace v1.2.0

Status: integrated local release candidate validated on 2026-09-15; not yet published.

ContextTrace v1.2.0 preserves `semantic_v1_calibrated` as the stable default and
adds two explicit experimental paths for source-aware verification. The release
also includes public investigations, framework gates, and captioned demos that
show the complete trace-to-regression workflow without a model API.

## Highlights

- Ships the opt-in `contexttrace verify-v2` command from `semantic_core_v2_1`,
  with bounded deterministic and pinned selective-NLI profiles. The stable
  `contexttrace verify` command remains unchanged.
- Adds `verify_trace_hybrid_v2`, `verify_traces_hybrid_v2`, and
  `verify_trace_file_hybrid_v2` behind explicit opt-in imports for lifecycle,
  version, conflict, scope, row-binding, and operation-order diagnostics.
- Adds separate v2.1 and `ClaimVerificationHybridV2` schemas and provenance
  identities so experimental results cannot be confused with frozen v1 output.
- Adds concise developer triage output and lets regression suites retain their
  selected stable or experimental verifier.
- Adds six reproducible investigations, 12 trace fixtures, 24 executable
  assertions, LangChain and LlamaIndex CI gates, and two captioned demos.
- Includes the MIT license in both the wheel and source distribution.

## Evaluation boundary

The v2.1 measurements in the changelog are visible development results rather
than untouched or state-of-the-art evidence. A separate controlled regression
evaluation found that `hybrid_v2` caught more faults while producing
substantially more false alarms and underperforming the stable default on the
balanced release-gate measure. Keep experimental profiles out of blocking CI
until they are calibrated on the target system.

Exact `hybrid_v2` study artifacts are excluded from this product release while
the related work is prepared for double-anonymous submission. This release
makes no broad
superiority or natural-traffic-generalization claim.

## Install and opt in

```bash
python -m pip install contexttrace==1.2.0
```

Stable verification remains the default:

```bash
contexttrace verify trace.json --format triage
```

Run the bounded v2.1 profile explicitly:

```bash
contexttrace verify-v2 trace.json --profile deterministic --json
```

Run `hybrid_v2` explicitly from Python:

```python
from contexttrace.verify import verify_trace_hybrid_v2

result = verify_trace_hybrid_v2(trace, mode="semantic")
```
